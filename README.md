# Glow Menu

Run the React website from the repository root:

```sh
npm install
npm run dev
```

The app lives in `website/app`. Root scripts forward to that app, including
`npm run build`, `npm run lint`, and `npm run preview`. Vite options can be passed
through, for example `npm run dev -- --host 0.0.0.0`.

See [the app README](website/app/README.md) for routes and environment setup.
The PHP and WordPress directories are the legacy site, not the npm dev server.
