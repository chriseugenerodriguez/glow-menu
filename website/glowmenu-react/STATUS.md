# Migration Status

## Implemented

- React routes for Home, Collections, Pricing, Contact, and Not Found
- responsive navigation, hero carousel, client marquee, and collection previews
- eight legacy menu collections
- interactive estimate and EmailJS-enabled inquiry form
- basic SEO metadata, structured data, sitemap, robots, and canonical URLs
- Vercel SPA routing and principal legacy commerce redirects
- optional environment-driven Google Analytics

## Required before launch

- configure and test EmailJS delivery
- verify all public copy, statistics, and prices with the business owner
- configure production analytics if wanted
- export the production WordPress URL inventory and add detailed redirects
- decide how long WordPress order and customer records must remain accessible
- complete production desktop, mobile, accessibility, and form testing

## Intentional scope

This is an inquiry-led replacement. WooCommerce, customer accounts, the Fancy
Product Designer editor, blog publishing, and Mailchimp subscriptions have not
been recreated. See `MIGRATION_AUDIT.md` for the complete comparison.
